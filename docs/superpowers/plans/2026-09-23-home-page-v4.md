# Home Page v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the home page to the "St Joseph Hospital Home v4" reference: nineteen bands in the logo purple and sky palette, light and dark, in all three languages, with every link leaving for a real page.

**Architecture:** The palette is a second set of values for the existing `--home-*` tokens, switched on by `data-palette="brand"` on the home shell, so the shared header, footer, toggles and floating rail follow it without any other page changing. `HomePage` stays a Server Component that fetches all copy once through `getHomeContent` and hands slices to sections; only the slideshow, the specialties carousel, the reviews carousel, the network accordion and the FAQ list are `'use client'` leaves. Copy lives in typed data files with Sinhala and Tamil overlays merged by `localize`.

**Tech Stack:** Next.js 16.2.11 App Router, React 19, TypeScript strict, Tailwind CSS v4 (CSS-first), `next/image`, `next/font/google` (Bricolage Grotesque and Manrope already loaded), `node --test` for data tests, Playwright (already in `node_modules`) for the browser pass.

**Spec:** `docs/superpowers/specs/2026-09-23-home-page-v4-design.md`. The decoded reference markup is beside it at `docs/superpowers/specs/2026-09-23-home-page-v4-reference.html`; each band is a `<section data-screen-label="...">` and the page data is the `<script type="text/x-dc">` at the bottom.

## Global Constraints

- Follow `CLAUDE.md`: routing in `app/`, logic in `features/home/`, `@/*` imports, Server Components by default, `'use client'` only on the leaves named above.
- Read the relevant guide in `node_modules/next/dist/docs/` before touching `next/image`, `next/link` or the Client/Server boundary. Do not code Next.js from memory.
- Never use an em dash in copy, comments or docs, in any encoding: the literal character, the named HTML entity, or either numeric entity form.
- Structured facts (an `href`, a `photo`, a stat `value`, an icon or tone key) have exactly one home in an English data file and are never restated in an overlay. A sentence that quotes a fact ("call 0117 84 84 84", "229/10 St. Joseph Street", "save 10%") is copy: it may appear wherever the reference puts it and is translated, and `src/lib/i18n/overlayNumerals.test.ts` pins that every numeral in the English sentence survives into the translation. The free OPD band alone keeps its figure-free rule (`bands.test.ts`), because that band's copy was written to carry none.
- House spelling wins over the reference: "X-ray", "in-house", "check-ups", "Medical Officer, Emergency".
- The register rule (`src/lib/i18n/registerPolicy.ts`): eyebrows, headings, titles, CTAs, chips, nav and footer stay English and are ABSENT from `*.si.ts` / `*.ta.ts`; body prose, stat descriptions, FAQ questions and answers, aria text translate. New overlays carry `export const __review = { status: "draft", reviewer: null, date: null } as const;`.
- `npm test` runs `node --test` over `src/**/*.test.ts` with Node's type stripping: data files and tests use relative imports with explicit `.ts` extensions and never import a `.tsx` file (type-only imports are fine).
- ESLint (`eslint-config-next`) forbids `setState` synchronously in a `useEffect` body and member access on a hook's returned ref (`useParallax(...).ref`); destructure it.
- `npx eslint src`, not `npm run lint`, until the sibling-worktree ignore lands (pre-existing issue).
- Every animation is disabled under `prefers-reduced-motion: reduce` through the existing media queries in `globals.css`.
- Never merge to `main`. Finish on `worktree-home-redesign-v4`, report, and stop.

```tsx
import type { ReactNode } from "react";
import { ThemeScript } from "@/components/theme/ThemeScript";
import { SiteThemeProvider } from "@/components/theme/useSiteTheme";
import { ThemedHeader } from "@/components/layout/ThemedHeader";
import { UtilityBar } from "@/components/layout/UtilityBar";
import { megaNavigation } from "@/config/megaNavigation";

type ThemedShellProps = {
  children: ReactNode;
  className?: string;
  /**
   * `"brand"` switches every `--home-*` token to the logo purple and sky set
   * (globals.css, `[data-sj][data-palette="brand"]`). Omitted, the page keeps
   * the default navy palette. The home page is the first to use it.
   */
  palette?: "brand";
  /**
   * `"fixed"` (default) floats the header over the hero, transparent until the
   * page scrolls. `"solid"` puts it in normal flow, sticky and always solid,
   * which is how the v4 home reference draws it.
   */
  header?: "fixed" | "solid";
  /** The dark emergency strip above the header. */
  utilityBar?: boolean;
};

/**
 * The themed root every page renders inside, and the one place the site
 * header is rendered. The header is fixed over the page by default, so it
 * lives here rather than in each hero (which pad their top by `--sj-header-h`
 * instead), and the navigation tree is read here, on the server, and handed
 * to the client header as a plain prop.
 */
export function ThemedShell({
  children,
  className,
  palette,
  header = "fixed",
  utilityBar = false,
}: ThemedShellProps) {
  return (
    <div
      id="sj-root"
      data-sj
      data-theme="dark"
      data-palette={palette}
      suppressHydrationWarning
      className={
        className ??
        "min-h-screen bg-[var(--home-bg)] text-[var(--home-body)] antialiased"
      }
    >
      <ThemeScript />
      <SiteThemeProvider>
        {utilityBar ? <UtilityBar /> : null}
        <ThemedHeader sections={megaNavigation} variant={header} />
        {children}
      </SiteThemeProvider>
    </div>
  );
}
```

```tsx
  return (
```

```tsx
/** The display heading most bands share: Bricolage, 34 to 54px, tight leading and tracking. */
export const displayHeading =
  "font-display m-0 text-[clamp(34px,3.8vw,54px)] leading-[1.02] font-extrabold tracking-[-0.03em] text-[var(--home-heading)]";

type PillVariant = "brand" | "outline" | "accent" | "surface";

/**
 * The reference's four pill buttons. `brand` fills purple and darkens on
 * hover; `outline` is a 1.5px ink border that fills ink on hover (the
 * `sj-invert` tokens); `accent` fills sky; `surface` is white on a brand
 * background. Height and padding vary per band, so the caller adds them.
 */
export function pillButton(variant: PillVariant): string {
  const base = "inline-flex items-center gap-2.5 rounded-full font-extrabold whitespace-nowrap transition-colors";
  switch (variant) {
    case "brand":
      return `${base} bg-[var(--home-brand)] text-white hover:bg-[var(--home-brand-hover)] hover:text-white`;
    case "outline":
      return `${base} sj-invert border-[1.5px] border-[var(--home-heading)] bg-[var(--home-bg)] text-[var(--home-heading)]`;
    case "accent":
      return `${base} bg-[var(--home-accent)] text-[var(--home-on-accent)] hover:bg-[var(--home-accent-hover)]`;
    case "surface":
      return `${base} bg-[var(--home-bg)] text-[var(--home-heading)] hover:text-[var(--home-brand-text)]`;
  }
}

/** The trailing arrow every CTA carries. */
export function ArrowRight() {
  return <span aria-hidden>&rarr;</span>;
}
```

```tsx
  countTemplate: string;
  findDoctor: { cta: string; href: string };

/**
 * Six chips over one card: the active tab's photograph on the left (fading in
 * on change), its title, paragraph and "top services" chips on the right, with
 * round brand arrows either side from `lg`. WAI-ARIA tabs: the chip row is a
 * `tablist`, arrows move the selection, the panel is labelled by its chip.
 * Every tab's links are rendered only when active, which is fine here: the
 * services index the "Explore more" button opens lists all of them for a

export function SpecialtiesCarousel({
  tabs,
  topServicesHeading,
  countTemplate,
  findDoctor,
  exploreMore,
  ariaPrev,
  ariaNext,
  locale,
}: Props) {
  const [index, setIndex] = useState(0);
  const baseId = useId();
  const active = tabs[index];
  const total = tabs.length;
  const step = (delta: number) => setIndex((i) => (i + delta + total) % total);

          const selected = i === index;
          return (
            <button
              key={tab.group}
              id={`${baseId}-tab-${i}`}
              role="tab"
              type="button"
              aria-selected={selected}
              aria-controls={`${baseId}-panel`}
              onClick={() => setIndex(i)}
              className={`h-10 rounded-full border-[1.5px] px-4.5 text-[12.5px] font-extrabold tracking-[0.06em] uppercase transition-colors ${
                selected
                  ? "border-[var(--home-chip-on)] bg-[var(--home-chip-on)] text-[var(--home-chip-on-fg)]"

            >
              {tab.label}
            </button>
          );
        })}
      </div>

          <HomeIcon name="left" size={22} stroke={2} />

          role="tabpanel"
          aria-labelledby={`${baseId}-tab-${index}`}
```

- [ ] **Step 2: Screenshots at three widths, both themes, three locales**

Write to the scratchpad and run with `node` from the worktree (Playwright is in `node_modules`; use `createRequire` against the worktree's `package.json` as `probe-design.js` did):

```js
const { chromium } = req("playwright");
const widths = [390, 768, 1440];
const paths = ["/", "/si", "/ta"];
const browser = await chromium.launch();
for (const theme of ["light", "dark"]) {
  for (const width of widths) {
    const context = await browser.newContext({ viewport: { width, height: 900 }, colorScheme: theme });
    const page = await context.newPage();
    for (const path of paths) {
      await page.goto(`http://localhost:3000${path}`, { waitUntil: "networkidle" });
      await page.evaluate(() => document.getElementById("sj-root")?.setAttribute("data-theme", window.matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light"));
      await page.waitForTimeout(500);
      const scrollWidth = await page.evaluate(() => document.documentElement.scrollWidth);
      if (scrollWidth > width) console.log(`HORIZONTAL SCROLL ${path} ${theme} ${width}: ${scrollWidth}`);
      await page.screenshot({ path: `${OUT}/${theme}-${width}${path.replace("/", "-") || "-en"}.png`, fullPage: true });
    }
    await context.close();
  }
}
```
