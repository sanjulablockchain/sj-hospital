## Adding to this list

Prefer the hospital's own photography. Where stock is unavoidable, use a
licence that permits commercial use without attribution (Unsplash License,
Pexels License) and record it here. Avoid Unsplash+ ("plus.unsplash.com"),
which is a paid licence, and avoid any photograph that shows another
institution's name or branding incidentally, in the background or by
accident.

This does not cover the group companies' own logos on `/network`: that page
displays them deliberately, as official marks rather than as photographs, and
carries its own on-page rights notice (`disclaimer` in
`features/network/data/content.ts`) covering exactly that use. Company logos
used this way belong in the table above like any other sourced image, not
excluded by this guidance.
